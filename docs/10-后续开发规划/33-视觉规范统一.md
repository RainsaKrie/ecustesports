# 视觉规范统一（2026-10-20）

> 目标：**收敛**，不是重设计。保持现有功能与布局不变，只把散落的样式收进有限几档。
> 基准仍是 `.workbuddy/ui-samples/schedule-public-v8.html`。

## 一、字号：四档，全部用令牌

**问题**：公开面有 `text-[0.625rem]` / `[0.6875rem]` / `[0.5rem]` 等十几处硬编码。
桌面根字号是 **150%**，`rem` 会被 ×1.5 —— 同一个 `0.625rem` 在不同上下文里看起来不一样。

**规范**：只用四档，写成 `--pub-fs-*`（px 定值，不受根字号影响）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--pub-fs-xs` | 11px | 眉标、表头、单位、时间戳 |
| `--pub-fs-sm` | 13px | 次要说明、表格次要列 |
| `--pub-fs-md` | 15px | **正文默认** |
| `--pub-fs-lg` | 17px | 区块标题、队伍名 |

大标题不在此列 —— 用 `clamp()` 单独控制（`--pub-fs-hero`）。

## 二、按钮：3 变体 × 2 尺寸

**问题**：`Button.tsx` 有 5 变体 × 4 尺寸 = **20 种组合**；另外全站还有 **52 处手写 `<button>`**，
各自写 `h-[44px]` / `px-5` / `bg-[#ff4655]`，尺寸与间距不统一。

**规范**：

| 变体 | 用途 | 样式 |
|---|---|---|
| `primary` | 每屏最多 1 个 | 红底白字 |
| `secondary` | 常规动作 | 1px 框 + 正文色 |
| `ghost` | 行内动作 | 无底无框，hover 才出现 |

尺寸只留两档：`md`（44px）/ `lg`（52px）。
`outline` / `dark-outline` **并入 `secondary`**（调用点不用改，组件内部做映射）。
手写按钮**逐个替换成 `<Button>`**，这是本批的主要工作量（52 处）。

圆角统一 `--pub-radius: 2px`（基准是硬边，不用圆角卡）。

## 三、颜色：只留一套

**问题**：色板外还有 39 处硬编码（`#ff4655` / `#d83b48` 之外的已收敛，剩余在 BP 页与零散位置）。

**规范**：以 `globals.css` 的令牌为唯一来源 —— `--pub-*`（公开面）/ `--adm-*`（后台）/ `--ui-*`（新主题层）。
强调色**只有一种红**：`#ff4655`，hover 用 `#d83b48`，暗底红字用 `#ff4655`（不用 `#c83242`，对比度不足）。

## 五、执行顺序与风险

1. **先加令牌**（不改任何页面）→ 门禁过 → 提交；
2. **再改 `Button.tsx`**（保持调用点兼容）→ 门禁过 → 提交；
3. **最后逐页替换手写按钮与字号**（分 3–4 批，每批跑门禁）。

**风险**：52 处手写按钮逐个替换，属于**机械但量大**的改动。
按批次做，每批提交一次，出问题只需回退一批。
**比赛期间不建议一次性推**，建议 23:00 后或无赛时段。
