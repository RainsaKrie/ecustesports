# UI 升级方案 v1.0（视觉 + 动效 + 可访问性）

> 2026-10-18。**前提**：把现有界面当成"不合格的基线"重做，不再做局部修补。
> 依据：对现有令牌的**实测**（对比度）＋ 首页已成型的设计语言 ＋ 外部规范（见第二节，均附来源）。
> 关联：`19 架构重构方案`（结构）、`20 开发计划`（阶段 3 设计系统 / 阶段 4 公开面）。

---

## 一、当前问题清单（每条都有证据）

| # | 问题 | 证据 | 后果 |
|---|---|---|---|
| 1 | **次要文字对比度不合格** | 实测 `--adm-text-mute #8a9199`：在白卡 **3.13:1**、在次一级底 **2.95:1**（正文要求 ≥4.5:1） | 弱光/投屏/手机上看不清；无障碍不达标 |
| 2 | **品牌红当文字用不合格** | 实测 `#ff4655` 在白底 **3.30:1**；白字在红底上同为 **3.30:1** | 只能用在大字与非文本；小字红字必须换 `#c83242`（5.18:1 ✅） |
| 3 | **没有字号与行高体系** | 令牌只有 5 档（12/13/15/18/24），无行高、无字距定义 | 页面各自拍尺寸；中文行距偏挤，长文难读 |
| 4 | **没有间距刻度** | 页面里直接写 `p-4`/`gap-2`/`mt-3`，无统一刻度 | 同类区块间距不一致，是"简陋感"的主因 |
| 5 | **没有动效令牌与状态切换设计** | 全仓库无 duration/easing 定义；状态变化是硬跳变 | 点击后"没反应"、加载时"白屏抖一下" |
| 6 | **交互反馈只有颜色变化** | 按钮/行/卡片只有 hover 变色 | 缺少按下、焦点、禁用、加载四种反馈 |
| 7 | **无 `:focus-visible` 规范** | 依赖浏览器默认轮廓（在深色卡上几乎不可见） | 键盘用户无法定位（WCAG 2.2 明确要求） |
| 8 | **无加载与空态体系** | 各页面自己写"加载中…"文字或什么都不显示 | 首屏抖动；操作后不知是否成功 |
| 9 | **响应式只有断点，没有策略** | 表格在手机上横向溢出；管理端控件按桌面假设 | 手机端（裁判/玩家主场景）体验差 |
| 10 | **两套语言没有边界** | 首页有海报语言（编号卡 / 反白 / 网格底），内页全无 | 从首页进内页有"掉档"感（负责人原话：设计消失了） |

## 二、参考规范与来源（取用 / 不取）

| 来源 | 取用 | **不取** |
|---|---|---|
| **Material Design 3 · Easing & duration**（m3.material.io/styles/motion/easing-and-duration） | 时长与曲线的**配对表**：Emphasized 500ms（起止都在屏内）/ Emphasized decelerate 400ms（进入）/ Emphasized accelerate 200ms（**退出**）/ Standard 300ms、decelerate 250ms、accelerate 200ms；CSS 曲线：standard `cubic-bezier(0.2,0,0,1)`、enter `(0,0,0,1)`、exit `(0.3,0,1,1)`、emphasized-decelerate `(0.05,0.7,0.1,1)`、emphasized-accelerate `(0.3,0,0.8,0.15)` | 不迁移到 M3 Expressive 的**弹簧物理**（需要改全部组件）；不引入 Material 组件 |
| **M3 高度模型** | **用色阶（tonal）表达层级，而不是阴影** | 不用投影 —— 与我们"无阴影、零圆角"的品牌约束天然一致 |
| **WCAG 2.2**（W3C） | 正文 **4.5:1**、大字与非文本 **3:1**；交互目标 **≥24×24 CSS px**（我们取更严的 44×44）；焦点指示器**至少 2px 厚、与相邻 ≥3:1**；尊重 `prefers-reduced-motion` | 不追求 AAA 全项（如焦点 4.5:1），先做到 AA 稳定 |
| **shadcn/ui** | **"组件源码归你所有、不做黑盒"** 的模式；组件清单与状态矩阵思路（60+ 组件，基于 Radix 的无障碍行为） | **不引入依赖** —— 我们已有 Tailwind 与自己的令牌，只借模式 |
| **Motion（framer-motion）** | `initial / animate / exit / whileHover / whileInView` 的心智模型；`AnimatePresence` 处理退场；**进入用弹性、退出用短补间**（"人看的是东西出现，不是离开"）；Radix 的 `forceMount` 让退场动画有机会播放 | 不整体引入：**能用 CSS transition 就不用 JS**（零运行时）；只有"列表增删、共享元素"这类才上库 |
| **性能规矩**（shadcn 手册 / 行业共识） | **只动 `transform` 与 `opacity`**；不动触发重排的属性；动效隔离在客户端小组件；"先测再猜，删掉不产生价值的动画" | 不做**滚动劫持**、不做大面积视差、不做装饰性循环动画 |
| **本仓库首页**（`globals.css` 的 `.section-kicker` / `.display-type` / `.brand-mark` / 34px 网格） | 把已成型的设计语言**制度化**：红眉标、海报大字、编号卡、反白卡缺角、网格纸底 | 不把海报语言搬进管理端（与"管理端不许深色填充/统计卡"冲突） |

## 三、升级方案

### 3.1 两套语言，一个色板

| | **公开面**（玩家看的：赛事主页 / 赛程 / 对战 / 战队档案） | **管理端**（负责人用的工作台） |
|---|---|---|
| 语言 | 海报体（72px 标题 / 编号卡 / 反白卡 / 网格底 / 红色 CTA 带） | 克制体（不上深色大卡、不用超大字号） |
| 共用 | 色板、间距刻度、字号刻度、动效令牌、焦点样式、零圆角、1px 结构线 | 同左 |
| 差异 | 允许 48/72 号字与反白块 | 标题 ≤24 号；主按钮=白底墨字+红条 |

### 3.2 字号刻度（新增行高与字距）

| 令牌 | 字号 | 行高 | 字距 | 用途 |
|---|---:|---:|---:|---|
| `--fs-display` | 72px（手机 48） | 0.94 | -0.03em | 公开面海报标题 |
| `--fs-h1` | 32px（手机 28） | 1.15 | -0.02em | 页面主标题 |
| `--fs-h2` | 24px | 1.25 | -0.01em | 区块标题 / 大数字 |
| `--fs-h3` | 18px | 1.4 | 0 | 卡片标题 |
| `--fs-body` | 15px | 1.65 | 0 | 正文（管理端默认） |
| `--fs-sm` | 13px | 1.6 | 0 | 次要文字 / 表格 |
| `--fs-xs` | 12px | 1.5 | 0.02em | 眉标 / 单位 |
| `--fs-mono` | 等宽（数字） | — | 0.04em | 比分、版本号、场次号（`tabular-nums`） |

### 3.3 间距刻度（4 的倍数，取代随手写的数值）

`--sp-1:4 · --sp-2:8 · --sp-3:12 · --sp-4:16 · --sp-6:24 · --sp-8:32 · --sp-12:48 · --sp-16:64`

规则：区块间距 `sp-8`/`sp-12`；卡片内边距 `sp-4`/`sp-6`；文字与边框 `sp-2`/`sp-3`；
**页面里不再出现裸的 `p-[13px]` 这类值**（验收会 grep）。

### 3.4 配色（修正 + 语义化）

| 修正项 | 现状 | 改为 |
|---|---|---|
| 次要文字 | `#8a9199`（3.13:1 / 2.95:1 ❌） | `#6f767e`（≈4.6:1 ✅）用于正文级说明；`#8a9199` 仅用于**非文本**（图标、分隔） |
| 品牌红当文字 | `#ff4655`（3.30:1 ❌） | 小字一律用 `#c83242`（5.18:1 ✅）；`#ff4655` 只用于**大面积/大字/边框** |
| 红底白字 | 3.30:1 ❌ | 红底上只用 **≥24px 或加粗大字**；小字改为深色字或加深红底 |
| 层级表达 | 靠阴影/边框混用 | **只用色阶**（surface / surface-2 / surface-3）+ 1px 结构线，不用投影（与 M3 高度模型一致） |

### 3.5 组件清单与状态矩阵

每个组件都要有 **五种状态**：默认 / hover / active / focus-visible / disabled，加载类再加 loading。

| 组件 | hover | active | focus-visible | loading |
|---|---|---|---|---|
| Button | 底色 → surface-2，边框加深 | `translateY(1px)` | 2px 红描边 + 2px 偏移 | 文案替换为「处理中」，**锁定宽度** |
| Input / Select | 边框 → 墨线 | — | 2px 墨线（或红条） | 右侧行内小转圈 |
| Table 行 | 底色 → surface-2 | — | 行内 outline | 首屏骨架 3 行 |
| Card（编号卡） | 右上 `+` 转 45° | 轻微下压 1px | 2px 红描边 | — |
| Modal | — | — | 关闭按钮可见焦点 | 内容区骨架 |
| Toast | — | — | — | 进入 250ms / 退出 200ms |

### 3.6 动效规范（时长与曲线全部取自 M3）

| 场景 | 时长 | 曲线 | 备注 |
|---|---:|---|---|
| 悬停 / 按下反馈 | **100–150ms** | standard `(0.2,0,0,1)` | 只改底色/边框/位移 ≤1px |
| 小面积出现（菜单、Toast） | **200ms** | enter `(0,0,0,1)` | 同时 8px 位移 + 淡入 |
| 中等面板（抽屉、弹窗） | **300–400ms** | emphasized-decelerate `(0.05,0.7,0.1,1)` | 进入稍慢、有"落定感" |
| 退出 / 关闭 | **200ms** | exit `(0.3,0,1,1)` | **退出一律比进入快** |
| 列表增删 | 200ms | standard | 只动 opacity + 高度用 transform 缩放替代 |
| 骨架 → 内容 | 150ms | standard | 交叉淡出，避免"跳一下" |
| 滚动进入（reveal） | 300ms，一次 | enter | 位移 ≤12px；**不劫持滚动**、不重复触发 |

**三条硬约束**：① 只动 `transform` / `opacity`；② `@media (prefers-reduced-motion: reduce)` 下
**全部关闭位移与缩放**（保留 ≤150ms 的透明度变化）；③ 不使用无限循环动画做装饰。

### 3.7 响应式（三档，策略而非断点）

| 断点 | 目标 | 策略 |
|---|---|---|
| ≤767 | 手机（裁判报分、玩家约赛） | 单列；表格**转卡片**（每行一张卡）；触控目标 **≥44×44**；关闭网格底（省渲染）；导航收进底部 |
| 768–1279 | 平板 / 小笔记本 | 两列；表格保留但隐藏次要列 |
| ≥1280 | 桌面（管理端主场景） | 现有多列布局；上下文条五格横排 |

### 3.8 性能与可访问性（写进验收）

- **对比度**：脚本扫全部文本令牌组合，正文 ≥4.5:1、大字/非文本 ≥3:1，**不通过即红**；
- **焦点**：`:focus-visible` 全覆盖，指示器 ≥2px、对比 ≥3:1，且不被 sticky 元素遮挡；
- **目标尺寸**：交互元素 ≥44×44（高于 WCAG 的 24×24 底线）；
- **键盘**：Tab 顺序符合视觉顺序；弹窗内焦点不逃逸；Esc 关闭；
- **动效**：`prefers-reduced-motion` 下零位移；单页同时运行的动画 ≤2 组；
- **不引运行时**：优先 Tailwind `transition-*` 与原生 `@keyframes`；只有列表重排/共享元素才考虑 Motion。

## 四、分阶段落地与验收

| 阶段 | 范围 | 交付物 | 验收判据（可机械检查） |
|---|---|---|---|
| **U1 令牌与基础组件** | 对比度修正、字号/间距/动效令牌、Button / Input / Chip | `tokens.css` + 三个原语 + `test:ui-guards` | 对比度脚本全绿；`test:ui-guards` 三条（裸间距 / 非 transform 动画 / 缺 focus-visible）全绿且**故意违反会红** |
| **U2 组件库** | Table（四态）、Modal、Toast、Skeleton、EmptyState、PageShell | `ui/` 目录 + 组件文档 | 每个组件五种状态齐全（逐项截图式核对由负责人点验） |
| **U3 管理端接入** | 赛程 / 抽签 / 报名 / 设置 / 运营 五页 | 页面瘦身 + 令牌化 | 页面里 grep 不到裸 `p-[` / `text-[length:`；单页 ≤300 行 |
| **U4 公开面** | 赛程 / 对战 / 战队档案（海报语言） | 三个公开页面 | 375px 无横向滚动；对比度全过；动效开关生效 |
| **U5 动效收尾** | 关键路径的进入/切换/加载动画 | 动效清单 + 实现 | reduced-motion 下零位移；单页动画 ≤2 组；无循环装饰动画 |

**排期建议**：U1 → U2 是地基（不动页面）；U3 与 U4 可并行（管理端与公开面不同文件）；
U5 最后统一收口。**每阶段单独提交、可回滚**，与前一轮架构重构的纪律一致。

## 五、明确不做

- **不引入组件库依赖**（不装 shadcn/Radix/Motion）：只借模式与规范，组件仍是我们自己的源码；
- **不做暗色模式**：当前无需求，且会让"零圆角 + 墨线"体系翻倍；
- **不做滚动劫持、视差、装饰循环动画**：与"克制"的调性冲突，且伤性能；
- **不迁移 M3 Expressive 的弹簧物理**：需要改全部组件，收益不抵成本。

## 六、改造范围分档（回答「是不是所有页面都要改」）

**不是。** 实测统计：管理端 14 个 `page.tsx` 里有 **9 个只有 6–18 行**（纯壳，渲染 Workspace 组件），
真正的界面在 **6 个大文件**里。所以要动的不是"三十个页面"，是**十来个文件**。

| 档 | 范围（实测规模） | 改什么 | 不改什么 |
|---|---|---|---|
| **D 不动** | **首页**（`app/page.tsx` 135 行） | 什么都不改 —— 它是**风格基准**，其它页面向它看齐 | — |
| **A 重做视觉** | 公开面：赛事主页 152 / BP 页 457 / 对阵页 / 公开赛程 | 排版、留白、编号卡、海报标题、动效 | 数据逻辑、交互流程 |
| **B 结构 + 令牌接入** | 管理端 6 个大件：抽签 947 / 赛程 892 / 报名 748 / 设置 609 / 审核 434 / 裁判 345 | 拆骨架、换令牌、补五态 | **业务判断不动**（只搬位置不改逻辑） |
| **C 只换令牌** | 报名表单 263 / 赛事管理 389 / 新建赛事 236 / 登录 83 / 站点内容 72 / 联系 44 | 间距、字号、颜色变量、焦点样式 | 布局与结构不动 |
| **不改** | 9 个 6–18 行的页面壳、数据类 lib、API 路由 | 无 | 全部 |

**结论**：真正"重画"的是**公开面 4 个页面**；管理端是"换装不换骨架"；其余只跟着令牌自动受益。

## 七、美术风格的保留清单（这是承诺，不是描述）

**不变**：
- 色板：暖白纸底 `#fffdf8` / `#f7f4ec`，墨色 `#171a1f`，结构线 `#d8d1c6`，品牌红 `#ff4655`；
- **零圆角**、**无阴影**、无渐变；
- 字体族：正文 system 中文 + `--font-geist-sans` / `--font-geist-mono`（数字与英文小标）；
- 首页那套语言：红眉标（30×2px 短横）、海报大字、编号卡 01–04、反白缺角、34px 网格纸底；
- 红只做强调：主按钮左侧红条、当前阶段反白、待处理数字。

**只动三处**：
1. **修不合格**：次要文字 3.13/2.95:1 → 换 `#6f767e`（≈4.6:1）；红字小号改 `#c83242`；补行高与字距；
2. **补缺失层**：动效令牌、`:focus-visible`、加载骨架、空态；
3. **延伸语言**：把首页的编号卡/海报标题用到内页与公开面（管理端只用弱化版）。

**明确不做**：不换美术方向、不加圆角/阴影/渐变、不做暗色模式、不引入第三方组件库的默认外观。
