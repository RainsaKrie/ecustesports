# QQ / 微信接入 —— 可行性调查 v0.1

> 2026-10-19，负责人提出「接入 QQ/微信」。**负责人明确要求：先收集信息探可行性，
> 可行才进入设计，要一步步来。**
> → **本稿只做可行性，不含任何技术设计。** 上一版写的模块结构（`domains/notify/adapters`）
> 属于设计，已删除 —— 那是"可行之后"的下一步。

## 一、先分清三种"接入"

| 形态 | 是什么 | 用户在哪一侧 | 门槛 |
|---|---|---|---|
| **A. 平台内展示** | 网站显示 QQ 群号 / 微信群二维码 / 客服号 | 他已经在网站上 | **零门槛**，改页面即可 |
| **B. 群机器人推送** | 赛程变更、开赛提醒、赛果自动发到 QQ 群 / 企业微信群 | 他在群里 | 需要群机器人 Webhook；**QQ 群机器人目前权限收紧** |
| **C. 公众号** | 赛事公告推文、菜单跳转网站 | 他在微信里 | **需要认证主体**（学校社团通常要挂靠）；订阅号不能主动推送 |
| **D. 微信个人号机器人** | 自动应答 | 他在微信里 | **违规，不做** |

## 二、可行性事实（2026-10-19 查证）

### A. 平台内展示 —— **可行，无政策风险**

网站首页与赛事页显示 QQ 群号（现为 `1107657580`）与群二维码。
**没有平台政策问题**，纯页面改动。唯一待确认：群二维码图片有没有现成的。

### B. QQ 群机器人 —— **官方接口能进群，但"主动推送"已被关闭**

查证于 QQ 开放平台官方文档（`bot.q.qq.com/wiki`）与开发者实践记录：

| 事实 | 对本案的影响 |
|---|---|
| **个人开发者现在可以拉机器人进 QQ 群**（以前只有企业实名可以） | 门槛降低 ✅ |
| 但**只能拉进"自己是群主/管理员"的群** | 你若是社长/群管理 → 可行 ✅ |
| **主动发消息功能已关闭，只能被动回复** | **"自动推送赛程 / 赛果"这条路走不通** ❌ |
| 拿不到用户 QQ 号、群号 | 无法做定向通知 ❌ |
| ark 卡片 / Markdown 卡片需 DAU 400–1000+ | 校园赛规模达不到 ❌ |
| 需要服务器 + 域名 + 证书 + **ICP 备案** | 域名有，备案情况待确认 ⚠️ |
| 官方接口稳定、不封号 | 这是它唯一明显优于第三方框架的地方 ✅ |

**结论**：QQ 官方机器人只能做「群内 @ 它、它回复」这类**被动查询**（例如"查我的下一场"），
**做不了"有变更就推群"**。而后者恰恰是办赛者最想要的那条。

### C. 企业微信群机器人 —— **能主动推送，但需要企业微信主体**

企业微信群机器人有官方 Webhook，**支持主动推送**（这是它与 QQ 官方机器人的关键差别）。
未在本次查证范围内核实"社团能否注册企业微信"，**列为待确认项**。

### D. 公众号 —— **门槛在主体认证，不在技术**

订阅号**不能主动推送**（服务号可以，但需认证主体）。学校社团通常要挂靠。
→ 只适合赛前公告、赛后战报这类不要求实时的内容。

### E. 微信个人号机器人 —— **不做**

违反平台规则，账号有封禁风险。**不在讨论范围。**

## 三、可行性结论（能不能做）

| 形态 | 能不能做 | 关键卡点 |
|---|---|---|
| A. 平台内展示 | **能，无卡点** | 需要群二维码素材 |
| B. QQ 群**主动推送** | **不能** | 官方接口已关闭主动发消息 |
| B'. QQ 群**被动查询**（@ 机器人问"我下一场"） | **可能能做** | 要搭建常驻服务 + 备案域名；价值取决于群活跃度 |
| C. 企业微信推送 | **待确认** | 社团能否注册企业微信主体 |
| D. 公众号 | **能，但周期长** | 主体认证；且不解决实时问题 |

## 四、还需要确认的信息（决定可行性）

1. **赛事主群在 QQ 还是微信**（决定 B 还是 C 有戏）；
2. 你在那个群里**是不是群主 / 管理员**（QQ 官方机器人只能进自己有管理权的群）；
3. 社团 / 学校**能不能注册企业微信**（决定 C 可行不可行）；
4. 域名 `ecustesports.top` **是否已备案**（QQ 官方机器人要求备案域名）；
5. 公众号有没有可用主体。

**这五项里，1、2、5 只有你知道；3、4 可以由我去查证。**

## 五、不建议现在做

- **公众号**：认证周期长，且不解决实时问题；
- **微信个人号机器人**：违反平台规则，账号风险不可控；
- **双向交互**（在群里查赛程）：需要常驻服务 + 长连接，校园赛规模不值当。

**当前建议**：只推进 **A（平台内展示）** —— 它无卡点、一天可完成。
**B / C / D 都先停在"信息未集齐"的状态**，集齐后再判断值不值得做，以及怎么做。
