### 测了什么指标

1. **横向溢出** —— 判据是 `document.body.scrollWidth > window.innerWidth`。
   **不用** `documentElement.clientWidth`：headless 下它会扣掉约 9px 滚动条，制造假溢出。
2. **触控目标尺寸** —— 所有 `input / button / select / textarea / a[href]`，判据 < 44×44px 即记为偏小。
3. **可横向滚动容器是否有操作提示** —— 页面不溢出但内部有宽表时，需要提示。

---

## 2. 结果：横向溢出

**全部 15 个页面 × 3 档宽度，全部无横向溢出。**

内容最宽处在 351–421px 之间，均不超过视口宽度。这与 OPN-09 此前对裁判端的结论一致。

个别页面存在**内部可横向滚动容器**（页面本身不溢出），见第 3.3 节。

## 3. 修了什么

### 3.1 破坏性操作触控区过小（最严重）

管理员「报名与队伍」页的选手卡片里，「编辑资料」「删除选手」原本只有 **40×15px**，
一排 20 组，且两者相邻。**15px 高度在手机上极难瞄准，而「删除选手」会移除报名数据。**

同类问题在队伍标签页还有 5 处（确认名单 / 开放调整 / 改名 / 解散队伍 / 整队退赛），
以及操作记录里的「撤销」。

修法：抽出一个共享常量 `textActionClass`（`inline-flex min-h-11 items-center`），
统一改到 44px 高。共 6 处文字型按钮 + 6 处队伍操作按钮。

| 按钮 | 修前 | 修后 |
|---|---|---|
| 编辑资料 / 删除选手 | 40×15 | 40×44 |
| 移出 / 换人 / 改角色 | 24×15 | 24×44 |
| 确认名单 / 改名 / 解散队伍 / 整队退赛 | 约 60×36 | 约 60×44 |

### 3.3 宽表格缺少横向滚动提示

赛事设置页的 5 个分区导航内容宽 **720px**，容器可视宽仅 **347px**，靠 `overflow-x-auto` 横向滚动。

页面本身不溢出，但**没有任何提示**。滚动条在部分手机上不显示，用户会以为只有前几个分区。

修法：在导航上方加一行提示「分区较多，可左右滑动查看」，仅在窄屏显示（`xl:hidden`，
因为 1280px 以上容器会取消最小宽度限制，不再需要滚动）。

### 3.4 顺手补的

报名页的 QQ 号与手机号输入框加了 `inputMode="numeric"`，手机上直接唤起数字键盘。

## 6. 没测到的部分

**必须明说，避免把局部结论扩大。**

1. **未测真实设备。** 全部在 headless Chrome 的视口模拟下测量。真机的软键盘弹起、
   刘海屏安全区、触控采样偏差都未覆盖。工作包验收清单里的「输入时软键盘不会遮住确认操作」
   **本次未验证**。
2. **未测完整业务流的操作结果。** 本次测的是布局与触控尺寸，没有逐条走完
   「建队 → 申请 → 审批 → 抽签 → 排期 → 报分 → 晋级」的操作结果验证。
   SYS-03 验收清单里的「每条关键路径可以只用触屏完成」只做到「元素可点」这一层，
   **没有做到「点下去结果正确」**。
3. **管理员的部分页面未覆盖。** `notifications`（通知）、`format`（赛制）、`report`（报告）
   三个页面未测。
4. **公开赛程与对阵的内部滚动未验证。** `/bracket` 页面测了无溢出，但没有验证对阵图
   内部横向浏览的可用性。
5. **未测 320px。** 工作包要求 360 / 390 / 430 三档，本次按此执行；OPN-09 此前测过 320px。

## 7. 怎么复现

探针脚本在 `.workbuddy/` 下（**不入库**）：

| 脚本 | 用途 |
|---|---|
| `mobile-probe.js` | 批量测公开页面：溢出 + 触控尺寸 |
| `player-probe.js` | 玩家侧工作台（需先取得参赛令牌） |
| `admin-probe.js` / `admin-page.js` | 管理员侧（脚本内自动登录） |
| `page-detail.js` | 单页深测：完整文本 + 控件明细 |
| `scroll-check.js` | 检查宽表格容器与滚动提示 |
| `team-tab.js` | 切换到队伍标签后测量 |

要点（都是踩过的坑）：

- **本地服务必须用 `http://localhost:<port>`**，不能用 `127.0.0.1`（Next.js 跨源保护会让组件 chunk 返回 403）。
- **浏览器状态不跨 node 进程保留**，所以「设令牌 → reload → 读取」或「登录 → 测多页」必须写在同一个脚本里。
- 测完**必须先停 dev 服务再还原数据**：服务运行时会写回数据文件，先还原会被覆盖。
