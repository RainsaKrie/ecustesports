# UI 重建 · 设计简报 v1.0（从零开始）

> 2026-10-18。负责人：「清零目前的 UI 设计，我们重新开始。」
> **重置的是设计方向，不是代码。** 已归档 10 份旧样板（`.workbuddy/ui-samples/archive/`）。
> 保留：38 套测试、依赖/UI 守卫、DataTable、PageShell、Skeleton、战队档案页 —— 这些与配色无关。

## 一、六轮反馈提炼：**确定不要的**

这些都是被明确否掉的，写下来防止重犯：

| ✗ 不要 | 他为什么否 |
|---|---|
| **米白 + 淡棕** | 「米白色和淡棕色不适合电竞」—— 那是书刊/文具的语汇 |
| **中性灰**（#8a9199 / #d3cfc7 这类） | 「灰色字体也不好看」—— 灰的问题是**没有色相**，不是深浅 |
| **纯黑 / 纯白** | 「对比度太高了，不好看」（16:1 那种） |
| **零圆角 + 1px 全硬边** | 观感是印刷品/表格，不是电竞产品 |
| **大留白 + 稀疏信息** | 显得空、不"专业"（参照平台的密度很高） |
| **只有一层的平色卡片** | 「卡片太简陋了，细节不够好」 |
| **单色强调（只有红）** | 「为什么不能丰富一下颜色」—— 颜色要**成对**，不是单调 |
| **无过渡的色块** | 「中间加一些过渡色比较好，比如蓝色」 |
| 软阴影 / 大圆角 / 毛玻璃铺满 | 试过，被认为"不够高级"，玻璃只能是点缀 |

## 二、**确定的偏好**

| ✓ 要 | 出处 |
|---|---|
| 暗底、**带色相**的暗（不是中性灰） | 参照两张图都是炭/酒红，不是灰 |
| **红→橙 / 红→紫→蓝** 这类渐变做主强调 | 参照2 的按钮与激活态；V6 的紫桥 |

| **斜切**边（平行四边形状标题条） | 两张参照图都有的"电竞签名" |
| 高**信息密度**、行高统一、靠对齐读 | 参照1 |

## 四、现实约束（不能假装没有）

1. **没有任何图片素材**：没有队徽、没有选手照、没有角色美术 —— 参照图里最抢眼的恰恰是这些。
   现阶段的替代方案只能是字母方块，或者**用图形/排版承担视觉重量**。
2. **中文只有系统字体**（苹方 / 雅黑）—— "高级感"的天花板在这里。要突破必须引字体（1–3MB，需 subset）。
3. **管理端要浅色**：负责人天天在后台干活，长文阅读和表格在深色下更累。

## 五、方法改一次（这是这次重建最重要的一条）

前六轮失败的原因不是执行，是**顺序**：我每次都直接出"整页样板"，用我的判断替代你的判断，
然后被整体否掉 —— 六次。

**新顺序**：
1. **先写规则**（这份简报 + 下一份 Design Spec：色板、字号阶梯、间距、圆角、渐变、卡片图层、
   动效时长）—— 只写规则，不出样板；
2. **你审规则**："这条对 / 这条不对"，逐条勾；
3. 规则定了**才出样板**，而且一次只出**一个组件**（不是整页）；
4. 组件过了再拼页面。

代价是多一轮确认，收益是不再整页返工。

1. **"公共面暗 / 管理端浅"这个分工还留吗？** 还是所有页面统一一个调子？
2. **有没有新的参照？** 上次那两张（完美赛事数据中心、瓦友社破晓杯）是"各有好坏"的，
   如果有更接近你想要的，给我一张，比什么描述都准。
3. **字体要不要引？** 不引的话，高级感有天花板；引的话要接受首次加载变重。
