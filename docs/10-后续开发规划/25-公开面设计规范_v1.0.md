# 公开面设计规范 v1.0（规则稿 · 待逐条确认）

> 2026-10-18。**这份只有规则，没有样板。** 每条前面有 `[ ]`，请勾「对」或写「不对」。
> 依据：`24-UI重建设计简报`（六轮反馈）+ 负责人本次答复：
> ① 问题在配色（米白/棕没有电竞的激情热血感）② 首页与部分卡片的设计**保留**
> ③ 参考无畏契约与完美电竞的**配色与卡片设计** ④ **设计种类太少**，列表与其他页面要多做
> ⑤ 全部暗色为主，但底色要选 ⑥ **字体引入**。

## 一、底色（负责人要求"要考虑"）

| 候选 | 值 | 优点 | 缺点 |
|---|---|---|---|
| A 炭黑 | `#14161a` | 中性稳、贴近完美电竞 | 偏冷灰，红橙渐变显"飘" |
| **B 蓝黑（推荐）** | `#11151d` | **红橙是它的互补色，渐变最跳**；青绿辅助能成立；长期看不腻 | 稍"科技"，不那么"血腥" |
| C 酒红黑 | `#1a1013` | 最热血、最贴近无畏契约 | **和红橙渐变同属暖色，贴在一起会糊**；看久了闷 |
| D 纯黑 | `#0a0a0c` | 对比最强 | 已被否（"太强"），且纯黑会压平细节 |

- [ ] **1.1 底色用 B 蓝黑 `#11151d`**（面板 `#171c26` / 二级 `#1e2431`）
- [ ] 1.2 顶部允许两处极淡光晕（红/紫各一，透明度 ≤22%），**不铺满**
- [ ] 1.3 页面外围允许一层极淡网格或噪点（透明度 ≤4%），压掉"AI 干净感"

## 二、配色系统（红橙是主，蓝紫是桥，青绿是辅）

| 角色 | 值 | 使用比例 |
|---|---|---|
| 主渐变 | `#ff3b2f → #f26522`（热血、照抄无畏契约的按钮语汇） | ≤10% 面积 |
| 过渡（桥） | `#c44a8c` 紫 → `#4f6ce0` 蓝 | 只出现在渐变里，不单独用 |
| 辅助 | 青绿 `#46d3c8` | 标签、Live 状态、进度 |
| 文字主 | `#e9eef7` | 正文与标题 |
| 文字次 | `#9aa7bb`（偏蓝的灰，**不是中性灰**） | 说明与单位 |
| 弱文字 | `#6b7789` | 场次号、时间戳 |
| 结构线 | `rgba(180,200,235,.12)` | 1px |

- [ ] **2.1 文字对比控制在 9–11:1**（不是 16:1，也不是 4.5:1）
- [ ] 2.2 主渐变只给：主按钮、当前阶段、获胜方比分、大数字
- [ ] 2.3 **颜色必须成对出现**（红橙 + 青绿），不允许单色铺满
- [ ] 2.4 禁止米白 / 淡棕 / 中性灰作为大面积底色

## 三、字体（负责人已同意引入）

| 用途 | 字体 | 说明 |
|---|---|---|
| 标题 / 数字 | **Noto Sans SC 900** + 拉丁 **Bebas Neue** 或 **Archivo**（condensed） | 中文靠 900 字重 + 负字距做出压迫感 |
| 正文 | Noto Sans SC 400/500 或 system-ui | 稳、易读 |
| 等宽数字 | **JetBrains Mono** / Roboto Mono | 比分、场次号、倒计时 |

- [ ] 3.1 通过 `next/font/google` 引入（CJK 自动按 unicode-range 切片，只下载用到的字）
- [ ] 3.2 中文标题 900、正文 400/500，**不用 600 灰态冒充层级**
- [ ] 3.3 大字号阶梯：`12 / 13 / 15 / 18 / 24 / 32 / 48 / 72 / 96`，最大与最小 **≥6 倍**

## 四、卡片与列表（**负责人指出设计种类太少，本节是重点**）

现有问题：全站只有一种"行列表"，所有页面都在复用。规范定义 **10 种基础形态**：

| # | 形态 | 用在哪 | 特征 |
|---|---|---|---|
| 1 | **比分牌** | 赛事页主视觉 | 大数字（54–96px）+ 双色条 + 地图名 |
| 2 | **比赛行** | 赛程列表 | 场次号 + 双队徽 + 大比分 + 状态 |
| 3 | **比赛卡** | 首页/赛程（卡片视图） | 竖排：阶段标签 + 两队 + BO + 时间 + 状态 |
| 4 | **阶段卡** | 赛事页/赛程顶部 | 编号 01–04 + 英文小标 + 完成数 |
| 5 | **队伍行** | 队伍名单 | 队徽 + 队名 + 阵容点阵（5+1+1）+ 状态 |
| 6 | **选手行** | 选手名单 | 头像位 + ID + 段位徽 + 所属队 |
| 7 | **统计格** | 全局/队伍页 | 小标签 + 大数字（4–8 格一组） |
| 8 | **进度条** | 阶段进度/BO 进度 | 双色、4–6px 高、直角 |
| 9 | **时间线** | 战队档案/赛事动态 | 竖线 + 节点 + 时间 |
| 10 | **空态 / 加载态** | 全局 | 骨架 + 一句"为什么空" |

- [ ] **4.1 以上 10 种都要做**（不是只做前 3 种）
- [ ] 4.2 每张卡至少三层：内渐变 + 顶部内高光 + 彩色外发光（**不用黑色阴影**）
- [ ] 4.3 圆角统一 4–6px；**允许**"斜切"只在标签类元素上出现（阶段标签、激活页签）
- [ ] 4.4 卡片间距 12px，行内 padding 14–16px，**密度参照完美电竞（行高约 44px）**

## 五、页面覆盖（每页要有自己的构图，不是同一套列表）

- [ ] 5.1 首页：主视觉 + 赛事卡网格 + 阶段进度 + 最新赛果（4 段）
- [ ] 5.2 赛事页：比分牌 + 阶段卡 + 页签 + 对应内容
- [ ] 5.3 赛程页：赛程视图切换（列表/卡片）+ 阶段筛选 + 日期分组
- [ ] 5.4 对阵页：双败/单败图节点（含状态色）
- [ ] 5.5 队伍名单：队伍行 + 阵容点阵
- [ ] 5.6 选手名单：选手行 + 段位徽
- [ ] 5.7 战队档案：队名大字 + 阵容 + 战绩 + 时间线

## 六、动效（基线，不展开）

- [ ] 6.1 递进 100/150/200/300ms，曲线沿用已定的 M3 组
- [ ] 6.2 卡片悬停：底色提一档 + 外发光加深，**150ms**
- [ ] 6.3 `prefers-reduced-motion` 下全部关闭位移
