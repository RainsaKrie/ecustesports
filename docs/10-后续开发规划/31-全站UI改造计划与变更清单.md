# 全站 UI 改造计划与变更清单

> 2026-10-20。**唯一 UI 基准**：`.workbuddy/ui-samples/schedule-public-v8.html`。
> 要求：布局结构 / 配色 / 字体排版 / 间距 / 图标 / 组件样式 / 交互状态 / 响应式，逐项对齐。
> 约束：**只改表现层**，不动业务逻辑、数据接口、路由与现有功能。

## 一、基准说明了什么（提炼成可执行的规则）

从 v8 里读出 8 条可复用的规则，后面所有页面都按这 8 条改：

| # | 规则 | 具体值 |
|---|---|---|
| 1 | **底色** | `#0a0b0d` + 海报底（径向红光 + 56px 细网格，图到位后叠 `--pub-bg-image`） |
| 2 | **卡片** | 半透明 `rgba(255,255,255,.05)` + `blur(14px)` + **1px 框线**（14%）+ **左上红折线 / 右下灰折线** |
| 3 | **框线强度** | `--pub-line` 22% / `--pub-line-soft` 14%（低于这个读不出"框"） |
| 4 | **文字三层** | 正文 `#f2f3f5`（17.7:1）→ 次要 64% → 灰 52%（5.26:1，过 AA） |
| 5 | **强调色** | 只有一种：`#ff4655`。用于眉标、句号、红折线、赢方比分、出线标记 |
| 6 | **排版** | 标题 `clamp()` 大字 + `tracking-[-0.04em]`；数字等宽 `tabular-nums`；**中文不用 mono** |
| 7 | **列表** | 六列固定顺序：时刻 / 阶段·轮次 / 队A / 比分 / 队B / 相距时间；表头极轻 |
| 8 | **间距** | 区块间距 24–42px；卡片内 12–18px；窄屏统一退化到两列 |

## 三、与基准无法完全对齐的部分（先说清楚）

| 部分 | 为什么对不齐 | 处理方式 |
|---|---|---|
| **管理端 13 页** | 基准是**公开赛程页**，后台没有任何参考；后台的信息密度、控件密度都不同（表格、表单、多选） | **沿用同一套令牌与卡片语言**，但布局按后台实际情况设计，不硬套公开面的六列/大标题 |
| **表单页（报名 / 设置）** | 基准里没有输入控件 | 输入框按"深底 + 1px 框线 + 聚焦红框"设计，与卡片同一套线 |
| **空态 / 加载态 / 错误态** | 基准是静态样板，无这些状态 | 统一用"框线卡片 + 一句说明"，不引入新样式语言 |
| **弹窗** | 基准无弹窗 | 半透明玻璃 + 遮罩 60% 黑 + 同一套框线 |
| **图标** | 基准里只有 `＋` 和折线，没有图标体系 | **不新增图标库**；沿用现有的少量符号，需要时用等宽字符表达 |
| **图片** | 负责人将提供官方海报 | 先留 `--pub-bg-image` 槽位，图到位后一行生效 |
