## 3. 问题台账

状态分为四类：**已修复** / **仍存在** / **已闭环（本轮）** / **无法确认**。

**分级说明（v1.1 修正）**：本台账拆分为「生产严重度」与「项目门禁」两个正交维度。

- **生产严重度**：只评价「当前已上线系统」的真实故障、安全风险与数据风险，分 P0 / P1 / P2。
- **项目门禁**：标记 RPT / AIE / 正式办赛前必须完成的前提条件，分 `RPT-BLOCKER` / `AIE-BLOCKER` / `EVENT-GATE`。
- **两者正交**：一个「未来能力缺失」即使必须在办赛前补，也不等于「当前线上故障」。
