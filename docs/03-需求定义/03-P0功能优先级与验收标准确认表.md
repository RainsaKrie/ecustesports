# P0 功能优先级与验收标准确认表

- 项目：《无畏契约》校园赛事 AI 排程协同助手
- 当前版本：1.0
- 文档状态：已确认并冻结
- 日期：2026-08-17
- 当前范围：只验证“赛程发布后的临时改期闭环”，不在本轮生成完整初始赛程

## 1. P0 要解决的任务

两队已经协商出新的比赛时间后，赛事负责人能够快速判断该时间能否批准；批准后形成唯一的新赛程版本，并生成一致的通知，避免人工反复核对赛程、漏查并发冲突和多处信息不一致。

## 2. P0 必须完成的功能

| 编号 | 功能 | P0 必须产生的结果 |
|---|---|---|
| F01 | 当前赛程与版本管理 | 系统保存当前唯一有效版本，并能识别基于旧版本提交的申请 |
| F02 | 改期申请 | 录入比赛编号、双方约定时间、原因和双方确认状态 |
| F04 | 确定性约束校验 | 检查比赛状态、队伍时间重叠、前后置依赖、赛事阶段范围和时段并发容量 |
| F05 | 冲突解释 | 明确指出违反的约束及受影响比赛，不静默放宽规则，不自动移动其他比赛 |
| F06 | 负责人审批与例外 | 负责人可批准、驳回；冻结比赛只能填写原因并重新开放后再校验 |
| F07 | 新版本与变更记录 | 每次批准都生成新版本，保留旧版本、操作人、时间、理由和变更内容，并可恢复旧版本 |
| F08 | 一致通知 | 按同一赛程版本生成给双方队伍、裁判和其他受影响对象的通知草稿 |

## 3. 本轮明确暂缓

- 完整初始赛程自动生成：临时改期闭环验证后再进入 P1。
- 收集所有队伍的完整可用时间、自动寻找双方共同时间。
- 每名裁判的个人日历与自动裁判指派。
- 直接写入腾讯文档、QQ 或微信；P0 先支持复制或导出结果。
- 报名、组队、奖品、赛后验收等大而全赛事平台功能。
- AI 自动批准、自动发布或自动作出处罚决定。

## 4. 建议验收标准

| 编号 | 验收标准 | 通过条件 |
|---|---|---|
| AC-01 | 单次处理效率 | 从提交一项双方已确认的改期，到生成可审批结果不超过 1 分钟；不计双方自行协商时间 |
| AC-02 | 硬约束可靠性 | 在 10 个可行案例和 10 个冲突案例中，不得把违反硬约束的方案判为可批准；冲突案例均指出正确的首要阻塞原因 |
| AC-03 | 审批前置完整性 | 旧版本申请、冻结比赛或缺少双方确认的申请，均不能直接进入批准状态 |
| AC-05 | 版本可追溯 | 每次批准均生成新版本，旧版本和变更原因可查看，且能恢复为指定旧版本 |
| AC-06 | 通知一致性 | 同一版本生成的所有通知中，比赛、时间和版本号一致，并覆盖预先识别出的全部受影响对象 |
| AC-07 | 完整闭环可用 | 负责人能连续完成 3 个预设改期任务，且无需再到另一张赛程表手工复查硬约束 |
