## 1. 数据性质分类（第①关 · 已确认）

按"数据怎么变化"分三类：

| 类型 | 含义 | 特点 |
|---|---|---|
| 覆盖式 | 改了直接覆盖 | 不留历史，简单 |
| 追加式 | 每次操作新增一条，从不修改 | 天然可追溯 |
| 版本式 | 每次变化生成新版本，旧版本保留 | 可回溯、可恢复 |

对象归类（2026-08-16 负责人确认）：

| 对象 | 归类 | 说明 |
|---|---|---|
| 赛事 | 覆盖式 | 基本信息，创建后基本不变 |
| 选手 | 覆盖式 | 报名信息，创建后基本不变 |
| 队伍 | 覆盖式 | 首发 5 人 + 1 替补（可选）+ 1 教练（可选） |
| 比赛 | 覆盖式 | 比分 / 状态 / 时间直接覆盖；改期历史由赛程版本承载 |
| 赛制 | 配置型（多套可选） | 分阶段结构，策划阶段决定，需预留多种 |
| 规则 | 配置型（多套可选） | 一届固定一套，但需预留多种；影响排程与校验等系统行为 |
| 赛程版本 | 版本式 | 每次改期审批通过生成新版本，保留历史可回溯 |
| 改期申请 | 追加式 | 一次申请一条记录，不可改 |
| 审批决策 | 追加式 | 一次决策一条记录，不可改 |
| 通知 | 追加式 | 一次通知一条记录，发出后不改 |

关键结论：

1. "比赛"对象只存当前时间，改期直接覆盖；改期历史（谁提、为什么、从几点改成几点）由"赛程版本"承载，可回溯。
2. "赛制"与"规则"是两个概念，都在赛事策划阶段决定；系统需预留多种赛制和多种规则供选择，不写死一套（对应 D-013 规则数据与排程逻辑分离）。
3. 队伍 = 首发 5 人 + 1 替补（可选）+ 1 教练（可选）；比赛期间只能换替补，无替补则不能临时换人。

## 2. 对象定义（第②关 · 已确认）

对象清单（10 个；原「规则版本」拆为「赛制」与「规则」，「审批」拆为「改期申请」与「审批决策」，报名内置新增「选手」）：

| 对象 | 身份 | 边界：不含 |
|---|---|---|
| 赛事 | 一届完整的校内赛 | 具体对局与排期 |
| 选手 | 一名报名选手 | 队伍归属 |
| 队伍 | 一支报名冻结后的队伍 | 比赛成绩 |
| 比赛 | 一场具体对局 | 整届赛程 |
| 赛制 | 分阶段结构定义 | 具体对阵 |
| 规则 | 一届约束规则 | 具体排期 |
| 赛程版本 | 整个赛程的快照 | 单场比赛 |
| 改期申请 | 队伍提交的一次改期请求 | 审批结果 |
| 审批决策 | 负责人对申请的决定 | 申请内容 |
| 通知 | 一次对外通知记录 | 生成逻辑 |

## 3. 对象关系（第③关 · 已确认）

关系分三组：

**组 1：赛事的从属（1 对多）**

| 关系 | 说明 |
|---|---|
| 赛事 → 选手 | 1 对多（一届约 160 人） |
| 赛事 → 队伍 | 1 对多（一届 32 支） |
| 队伍 → 选手 | 1 对多（首发 5 + 替补 0~1 + 教练 0~1） |
| 赛事 → 比赛 | 1 对多（一届几十场） |
| 赛事 → 赛制 | 1 对 1（本届选一套） |
| 赛事 → 规则 | 1 对 1（本届选一套） |

**组 2：比赛的关系**

| 关系 | 说明 |
|---|---|
| 比赛 ↔ 队伍 | 一场 2 队，一队多场 |
| 比赛 → 赛制阶段 | 归属哪一轮 |
| 比赛 → 比赛 | 前置依赖（晋级关系） |

**组 3：改期闭环（P0 核心）**

| 关系 | 说明 |
|---|---|
| 比赛 → 改期申请 | 1 对多（一场可多次改期） |
| 改期申请 → 审批决策 | 1 对 1（驳回后重新提交 = 新建申请） |
| 审批决策 → 赛程版本 | 批准生成新版本，立即生效同步 |
| 赛程版本 → 通知 | 1 对多 |

关键关系决策（2026-08-16 确认）：

1. **赛制按阶段锁定**：正在进行的阶段赛制不可改，未开始阶段的赛制可改（如入围赛进行中，小组赛/淘汰赛赛制可改，入围赛不可改）。
2. **改期申请驳回后 = 新建**：重新提交是一条新申请（严格 1 对 1）。
3. **审批通过 = 立即生效**：生成新赛程版本并同步对外，无需二次发布。
4. 替补本届仅 1 个（上届手册的 2 替补不采用）。
5. **规则改动不回溯**：规则（并发上限、时长等参数）改动只影响之后的校验，不回溯已发布/进行中的赛程。

## 4. 状态流转（第④关 · 已确认）

| 对象 | 状态值 | 说明 |
|---|---|---|
| 赛事 | 筹备中 → 报名中 → 进行中 → 已结束 | 删除即取消 |
| 选手 | 已报名 → 已入队 → 已退赛 | |
| 队伍 | 报名中 → 已冻结 → 已退赛 | UI：有空位 / 完整队伍 / 灰掉 |
| 比赛 | 待排期 → 已排期 → 进行中 → 已完成 | 另有冻结标记；弃权判负 |
| 赛制 | 无状态（纯配置） | |
| 规则 | 无状态（纯配置） | |
| 改期申请 | 待确认 → 待审批 → 已批准 / 已驳回 | 驳回后新建 |
| 审批决策 | 批准 / 驳回（结果值） | |
| 赛程版本 | 当前有效版（唯一）/ 历史版（被替代） | 审批通过立即生效 |
| 通知 | 草稿 → 已发送 | |
