# UI 设计规格 v0.2（以现有首页设计为基准）

- 项目：《无畏契约》校园赛事 AI 排程协同助手
- 文档状态：已确认（2026-08-17，修订自 v0.1）
- 适用范围：现有与未来的全部界面
- 原则：**现有首页设计即标准**。新界面优先复用首页既有组件与视觉语言；「赛事信息四栏导航」描述仅作补充灵感，不照搬，不与现有语言冲突

## 一、硬性规则

1. **全站禁用圆角**（D-037）：任何组件不使用 border-radius；圆形装饰改为 45° 旋转方形
2. 信息层级清晰、无冗余装饰、无动画堆砌（海报等赛事物料除外）

## 二、设计令牌（globals.css :root，代码即标准）

| 令牌 | 色值 | 用途 |
|---|---|---|
| --paper | #ece8df | 页面底色（暖白） |
| --paper-deep | #dfdbd1 | 深一档底色 |
| --ink | #0f1923 | 深炭蓝：结构线、深色块、主文字 |
| --ink-soft | #25313b | 深色块的浅一档 |
| --muted | #667078 | 次要文字 |
| --line | rgba(15,25,35,.2) | 弱结构线 |
| --red | #ff4655 | 品牌红：主按钮、导航、强调 |
| --red-dark | #d83b48 | 暗红：英文副标题/meta 小字、hover 态 |
| --white | #f7f5ef | 深色底上的浅色文字 |

## 三、背景与字体

- 页面底：`--paper` + 48px 淡网格纹理（body background，已实现）
- 字体：Geist Sans 正文 + Geist Mono 辅助（编号、meta、导航、标签）+ 窄体 display 标题
- 字号基准：html font-size 150%（rem 单点控制）
- 标题：字重 820、letter-spacing -0.07em、clamp 响应式
- 英文小标签：mono、全大写、字距 0.12em+、red-dark

## 四、形状语言（无圆角的具体形态）

| 元素 | 形态 |
|---|---|
| brand-mark | 左上切角（clip-path）+ 内描边 |
| btn-cut 按钮 | 右下切角 + 内描边 + hover 上浮 2px |
| capability-card | 右下切角（三角补白） |
| signal-strip 分隔符 | 7px 旋转 45° 菱形 |
| 装饰环 | 45° 旋转方形描边 |
| 结构网格 | 1px --ink 实线分隔（非圆角卡片分隔） |

## 五、首页组件规范（复用基准）

1. **site-header**：ink 深顶栏；mono 导航项 + 下划线动效；「工作台」红底切角按钮（内描边 + 上浮）
2. **hero 主视觉**（EventsCarousel）：海报全幅 + 左侧大标题（display 窄体）+ 竖排 rail 文字 + 切角按钮（主红/暗描边两种）
3. **signal-strip**：红底白字 mono 信号条，菱形分隔，点击直达详情页对应 tab
4. **section-heading**：超大标题 + 左侧 1px 竖线 aside 说明
5. **capability-card 四栏模块**：1px ink 网格四等分；半透明白底；左上 mono 大编号、右上红色 ＋、英文 meta（红暗色 mono 小字）、中文标题、正文；hover 反转深底 + 上浮（深色块语言）
6. **event-card**：切角视觉区 + serial 编号 + 状态 chip
7. **closing-cta**：ink 深色块 + 大标题 + 红色切角按钮

## 六、状态表达

- 当前状态/激活态：**深色块（ink 底 + 白字）**，可配切角 —— 与 capability-card hover 态同语言
- 阶段驱动（如四栏模块激活位随赛事阶段变化）可在此语言上加，不引入新视觉
- 状态 chip：mono 小字 + 细边框 + 语义色（绿/琥珀/灰）

## 七、后台工作区

- 白卡 + slate 结构线（已全直角），与前台共享红色主按钮语言
- 不引入新配色与装饰，保持工具感

## 八、与「四栏导航」描述的关系

四栏描述中的可取之处（大编号层级、激活模块深色切角、等宽网格）在现有首页 capability-card 中已具备或可平滑增强；其具体色值（#C0392B 等）不采用，保持现有令牌。
