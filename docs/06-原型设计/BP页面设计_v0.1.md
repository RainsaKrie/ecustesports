## 2. BP 房间 `/bp/[matchId]`

现场主页面，投屏/手机双场景。深色底（沿用现有 `#0f1923` 风格），大字排版。

### 2.1 布局（从上到下）

```
┌────────────────────────────────────────────┐
│ 顶栏：Mxx · 小组赛A组首轮 · BO3          [退出] │
│ 队伍条：  [A 队名·先手]      VS      [B 队名] │
│ 当前提示： ▶ A 队请 Ban 一张地图（第 2/4 步） │
├────────────────────────────────────────────┤
│            地图网格（7 张卡片）              │
│   已禁=红色斜线遮罩 · 已选=绿色✓ · 可选=亮   │
├────────────────────────────────────────────┤
│ 流程条：A禁 → B禁 → A禁 → B禁 → A选 → B选 → 决胜 │
│ 操作记录（第1步起，含操作方/角色/时间）      │
└────────────────────────────────────────────┘
```

### 2.2 地图卡片状态

卡片底图 = 地图原画（暗色渐变遮罩保证地图名可读），地图名使用中文。

| 状态 | 视觉 |
|---|---|
| 可选 | 原画全亮 + 悬停红色边框 |
| 已 Ban | 红色边框 + 斜线遮罩 + 「BAN」角标 + 操作方 |
| 已 Pick | 绿色边框 + 「✓ PICK」角标 + 序号（第几局图） |
| 决胜图（BO3 自动） | 黄色角标「决胜图」，出现在流程条末端 |

### 2.3 身份与操作区

- **未识别身份**（游客/成员）：顶部黄条提示「当前身份不能操作，请联系队长或裁判」，地图不可点。
- **队长**：轮到本方步骤时提示变亮、地图可点；点击即提交该步（无二次确认，支持回退）。
- **裁判（后台登录）**：顶部出现工具条：
  - 「掷骰子比大小」（双方各掷一颗，点数大者先手，两个点数都展示，平局重掷）
  - 「交换先手」（手动）
  - 「回退一步」「重置 BP（含先手结果）」
  - 可代任意一方完成当前步骤

### 2.4 流程条与记录

- 流程条按 `buildBPOrder` 生成：每步一个节点，展示先手方标识与 Ban/Pick，当前步高亮，已完成步打勾。
- 决胜图节点在 BO3 末端（黄色）；BO1 的流程条 = 6 个禁步 + 1 个「唯一图」节点；BO5 无决胜节点。
- 操作记录列表：`1. A队 禁用 Bind（队长） 19:32`，裁判代操作标注「（裁判）」。

### 2.5 完成态

- 全部步骤完成后：顶部大号结果展示「比赛地图：Bind、Haven、决胜图 Split」+ 绿色完成徽标。
- 提示「结果已写入赛程，可开始比赛」；下方保留完整记录供回溯。
- 已完成的会话不再可操作；报分页逐局选图下拉自动带出这些地图。

## 3. BP 列表 `/bp`

- 比赛卡片：对阵 + BO 类型 + 开赛时间 + BP 状态徽标（未开始/进行中 x/y 步/已完成）。
- 已完成卡片显示最终选图列表（小字）。
- 点卡片进房间。

## 4. 地图池设置（赛事设置页新区块）

- 「地图池」区块：展示当前启用的地图（默认排位图池 7 张），每张带「停用」按钮。
- 「添加地图」：输入地图名手工添加（用于随排位轮换替换地图池；替换操作由人工完成，系统不自动同步游戏版本）。
- 停用校验：剩余 < 5 张时红色提示「BO5 需要至少 5 张地图」，仍允许保存但 BP 房间对 BO5 场次提示不可用。
- 保存后前台 BP 房间即时生效（读配置）。
