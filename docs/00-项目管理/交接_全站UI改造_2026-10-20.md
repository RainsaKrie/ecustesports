## 七、施工纪律（改这个仓库前必读）

**锁行文件（架构基线：只许变短，不许变长）**
`globals.css`（现 1018 行基线）、`manage/page.tsx`（389）、`RefereeWorkbench`（881）、`bp/[id]`（457）、
`FormatDrawWorkspace`（980）、`RegistrationOperationsWorkspace`（778）、`EventSettingsWorkspace`（609）、`ReviewWorkspace`（434）、`admin/events/[id]/schedule/page.tsx`（895）。

→ 改这些文件只能**行内替换 class**，不能加行；要加就先删等量行。

**新增文件**：`.css` > 400 行即违规（`pub-theme.css` 现 339，`admin-theme.css` 121，余量不大）。

**Tailwind 注意**
- TSX 里不许手写 `p-[13px]`/`m-[…]` 这类间距 → ui-guards 会红；间距写进 CSS 类
- TSX 里不许出现色板外的 6 位 hex → color-guards 会红；用 `var(--…)`
- **千万别在新目录写含 Tailwind 类名的笔记**：Tailwind v4 自动扫描非 gitignore 目录，会把笔记里的类名编进生产 CSS（已踩过，`/tmp/` 已 gitignore）

**根字号**：桌面 `html { font-size: 150% }`，所以 `text-sm`/`h-16` 这类都会 ×1.5。

## 十、踩过的坑（省得重踩）

| 现象 | 原因 | 处理 |
|---|---|---|
| `npm run gate` 偶发 `ACCESS_VIOLATION`（0xC0000005） | 本机内存吃紧时 Node/Turbopack/eslint 崩溃 | **原样重跑即可**，不是代码问题；CI 未出现 |
| gate 报失败但单跑都过 | dev server 与 `next build` 抢 `.next` | 跑 gate 前先停 dev server |
| agent-browser 所有命令无输出/挂死 | 残留 headless Chrome（`--remote-debugging-port=0` + 临时 profile）占锁 | `taskkill /PID <chrome> /T /F` 后恢复；`open` 设计上不自退，要「启动→等 9–10s→杀进程」 |
| 整页泛红 | 海报底 `radial-gradient(circle …)` 无尺寸，默认 farthest-corner 在高容器上算出巨大半径 | 显式给 `circle 1100px` / `circle 900px` |
| 站头导航折行 | 150% 根字号下 nav 26px + 每项 28px 内边距，容器收窄后被压 | 站头用 px 定值覆盖 |
| 弹窗内容看不清 | 弹窗用了玻璃卡底（5% 白），背后标题透出来 | 新增 `.ui-modal-panel`（不透明 `var(--pub-bg)`） |
| `indexOf("}\n}")` 删错一大段 | 从 `/tmp` 笔记生成的 patcher 按字符串定位，撞上嵌套大括号 | 改按**行号**删除；删完核对花括号数与关键选择器数量 |
| PowerShell 里中文乱码/解析错 | 控制台编码 + `|` 接在 for 块后 | 用 `read` 工具读文件；脚本拆分多条命令 |
| git commit 中文消息里有双引号被当 pathspec | PowerShell 传参 | 消息写进文件，用 `git commit -F` |
