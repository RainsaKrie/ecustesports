### ② 建裁判账号 —— 10.7 前必须做

**为什么**：裁判报分开关已开，但**一个裁判账号都没建**，这套系统至今没被真人用过。
开赛当天才建会来不及（凭证只显示一次，要当场分发给每个裁判）。

**怎么做**：

1. 登录 `https://ecustesports.top/admin/events/event-1/referees`
   （已验证：未登录访问会返回登录页，不泄露管理内容）
2. 填「裁判姓名」（例如：张三）
3. 有效期可不填（默认 90 天，覆盖整个赛期）
4. 点「创建裁判」→ **页面立刻显示一次凭证**，必须当场复制保存
5. 把凭证 + 下面这个地址发给该裁判

**裁判要访问的地址**：
```
https://ecustesports.top/referee?eventId=event-1
```
（已验证可访问，HTTP 200）
裁判打开后需输入两项：**裁判凭证** + **赛事 ID**（`event-1`，带参数进去会自动填好）。

**⚠️ 三个必须提前告诉裁判的事**：

1. **刷新或关掉页面后凭证要重新输入**（页面内存保存，不落 cookie）。
   建议他们自己把凭证存在手机备忘录里，否则每刷新一次就要找你重发。
2. **一场比赛只能有一名裁判**。谁先认领算谁的；被认领后别人抢不到。
3. **认领后要自己看哪些能裁**——不是分配制。列表里「可认领的比赛」是他们自己挑的。

**做完的标志**：至少一名真实裁判登录成功、看到比赛列表。
（这正是 RPT-07 验收清单里唯一还没打勾的一项。）

**为什么**：服务器在新加坡，国内访问时好时坏（已知风险）。要确认在你的实际场地能用。

**怎么做**：在以下三种网络各测一遍 **首页 / 赛事页 / 参赛中心 / 一次写操作**（如报名或改资料）：

**做完的标志**：三网都能打开且能提交；若某个网络打不开，现在就暴露出来比开赛当天好。
