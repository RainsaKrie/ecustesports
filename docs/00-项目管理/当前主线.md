## 五、验证与交付链（每次改完照这个走）

1. `CODEBUDDY_SAFE_DELETE_ENABLED=0 npm run gate`（lint → typecheck → 42 套 → 构建）；
2. 推送后**必须查 CI**：`gh run list --limit 1` 看最新一条。**判断推没推只能用 `ls-remote`，不能用本地 `origin/main` 跟踪引用**（它是过期的）；
3. 动写路径前先想三处登记：**写入点清单 / 鉴权登记 / 留痕归属**；
4. 界面改动**未经真浏览器验收**时，必须在提交说明里写明。
